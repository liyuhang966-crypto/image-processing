# 图像几何变换

## 章节定位

第 3 章是本知识库的第二个精品样板章节，重点围绕坐标映射、反向采样、插值和几何校正建立学习路径。

## 学习主线

1. 先理解位置变换：平移、镜像、旋转。
2. 再理解形状变换：缩小、放大、错切。
3. 用齐次坐标把基本变换统一为仿射矩阵。
4. 最后把坐标映射思想扩展到几何畸变校正。
