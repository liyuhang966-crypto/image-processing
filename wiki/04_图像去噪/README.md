# 图像去噪

## 章节定位

第 4 章是第 4-11 章批量精修的起点，围绕噪声模型、局部滤波、边界保持和平滑质量评估建立学习路径。

## 学习主线

1. 先判断噪声类型。
2. 再选择均值、中值、边界保持或非局部均值滤波。
3. 对比噪声抑制、边缘保持和计算量。
4. 把去噪结果连接到第 5 章锐化和第 6 章分割。
