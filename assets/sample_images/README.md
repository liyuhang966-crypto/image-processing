# 合成示例图片

本目录由 `examples/_common.py` 自动生成可自由提交的合成测试图片，用于验证示例脚本能独立运行。

- `sample_gray.png`：灰度渐变、圆形和矩形组成的合成灰度图。
- `sample_color.png`：由合成灰度图派生的三通道彩色图。
- `sample_noisy.png`：在合成灰度图上加入高斯噪声和椒盐噪声，用于第 4 章去噪示例。
- `sample_segments.png`：包含多个亮度区域和轻微噪声的合成图，用于第 6 章分割示例。
- `sample_binary.png`：包含多个二值目标、小孔和小噪点，用于第 7 章二值处理示例。

这些图片不是原书图片，也不是从 PDF 中截取的内容。
